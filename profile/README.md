# Family Care Cloud ☁️

### 가족이 함께 기록하고 이어가는 어르신 돌봄 서비스

돌봄 기록을 한곳에 모으고, 보호자가 바뀌어도 필요한 정보를 이어갑니다.

## 레포지토리

| 레포 | 설명 |
| --- | --- |
| [fcc-frontend](https://github.com/FamilyCareCloud/fcc-frontend) | 가족 보호자가 사용하는 웹 프론트엔드 |
| [fcc-backend](https://github.com/FamilyCareCloud/fcc-backend) | 돌봄 기록, 일정, 가족 그룹, 인수인계를 관리하는 백엔드 API |
| [fcc-ai](https://github.com/FamilyCareCloud/fcc-ai) | AI 인수인계와 돌봄 기록 분석 |

## 프로젝트 소개

**Family Care Cloud**는 여러 가족 구성원이 번갈아 어르신을 돌볼 때 생기는 정보의 단절을 줄이기 위한 서비스입니다. 가족이 돌봄 기록과 일정을 공유하고, 담당 보호자가 교대할 때 다음 보호자가 알아야 할 내용을 인수인계할 수 있도록 돕습니다.

**가족 그룹 생성 → 어르신 등록 → 돌봄 기록·일정 공유 → 보호자 교대 → 인수인계 확인**

## 핵심 기능

| 기능 | 설명 |
| --- | --- |
| 가족 그룹 | 어르신을 중심으로 가족을 초대하고 함께 돌봄 정보를 관리합니다. |
| Care Timeline | 병원, 복약, 식사, 생활 등 돌봄 기록을 시간순으로 확인합니다. |
| 일정 관리 | 진료, 검사, 방문 등 예정된 일정을 공유하고 담당 보호자를 지정합니다. |
| AI Care Handoff | 보호자 교대 시 최근 기록과 예정 일정을 바탕으로 필요한 내용을 정리합니다. |
| 인수인계 확인 | 다음 보호자가 전달받은 내용을 확인하고 확인 이력을 남깁니다. |
